# 30万订阅以上中文 YouTube 频道 · 2026

- `chinese_youtubers_300k_2026.csv`：290 个频道，可以直接用 Excel 打开（UTF-8 BOM 编码）
- `chinese_youtubers_300k_2026.json`：同一份数据的 JSON 版本
- `../scripts/nox_parse.py`、`../scripts/nox_merge.py`：解析榜单页面、合并去重、计算估算值的脚本

## 数据来源

NoxInfluencer 公开排行榜，更新于 2026-11-14。覆盖 12 个地区（中国大陆、台湾、香港、马来西亚、新加坡、美国、日本、加拿大、澳洲、英国、韩国、泰国），每个地区取 4 种排序（订阅、平均播放、增长、NoxScore）的榜单，合并去重后保留两类频道：订阅 ≥ 30 万，且频道名或最新视频标题是中文。

## 字段

| 字段 | 含义 |
|---|---|
| 近30天新视频播放 | Nox 的 "30-day video view count"，即近30天内发布的视频获得的播放量（不含老视频的长尾播放） |
| 平均每支播放 | 近30天新视频的平均播放 |
| 2026年播放（估算） | 近30天新视频播放 × 323/30（2026-01-01 至 11-19） |
| 收入（SB口径） | 播放 / 1000 × $0.25–$4（Social Blade 公开算法） |
| 收入（Shorts校正） | 按 Shorts 占比加权：Shorts 每千次 $0.02–$0.08，长视频每千次 $0.5–$3；只算广告分成 |
| 周订阅增长% | Nox 给出的近一周订阅变化比例，精度 0.1% |
| 2026新增订阅（估算） | 订阅数 × 周增长率 × 30/7 × 323/30 |
| 类型 | 按频道名关键词自动判断是个人/工作室还是机构/官方，可能有误 |

## 局限

1. **覆盖不完整**：每个公开榜单只有前 100 名，所以这份名单没有包含全部 30 万+ 中文频道（实际可能有上千个）。Social Blade 拦截了自动访问，频道详情页需要付费登录，所以都没有用到。
2. **2026 年数字是外推**：Nox 没有公开全年的历史数据，所以用近 30 天的数据按天数外推。近一个月爆发的频道会被高估（例如 GTA6-罪恶都市），休更或只靠老视频的频道会被低估甚至显示为空。
3. **收入只是广告分成的估算**：不含赞助、会员、带货，实际 RPM 因受众地区差异很大。
